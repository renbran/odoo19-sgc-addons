# SGC TECH AI - Installation

## Requirements

- Odoo 19
- PostgreSQL

## Steps

1. Copy `sgc_theme_ai` into your custom addons directory.
2. Restart Odoo if needed.
3. Update the apps list.
4. Install `SGC TECH AI - Premium Theme`.

## Verified Local Access

- URL: `http://localhost:8069`
- Review database: `sgc_theme_ai_fullpath_20260314_b`

## Expected Result

- Homepage opens on `/home`
- Marketing pages return `200`
- `/solutions` is available
- Theme assets compile through the Odoo 19 asset pipeline
