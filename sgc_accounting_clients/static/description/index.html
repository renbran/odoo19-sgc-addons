SGC Accounting Clients

Client document portal and accounting agent intake

Portal for accounting clients to upload documents into nine intake buckets, with downloadable CSV format guides, per-bucket validation and a durable agent outbox. Accepted documents are queued for the accounting agent, which extracts values and proposes matches. Every amount is checked against the uploaded file before a result is stored, and nothing is ever posted to the ledger automatically.

  • Nine upload buckets with generated sample CSV files.
  • Per-bucket required columns, aliases and accepted formats.
  • Durable agent runs with retries, signed downloads and callbacks.
  • Deterministic checksum gate before any agent result is accepted.
  • Accountant review activity whenever a result needs confirmation.
