Aurum Backend Theme

A calm, high-contrast skin for the Odoo web client.

Aurum restyles forms, lists, kanban, search and printed reports in a warm navy / gold / cream palette with elegant serif headings — improving readability without changing behaviour, breaking OWL components, or slowing down data entry.

Built for clarity

  • WCAG-AA contrast on text, table rows, field borders, badges and status colours.
  • No 3D, no heavy animation. Only subtle, fast hover/focus micro-transitions.
  • Every transition honours prefers-reduced-motion.
  • Stronger list row separation, sticky headers and an accessible selection highlight.
  • Cleaner kanban cards with a gold accent bar and readable badges.
  • Density-safe spacing so records stay compact.
  • A light, print-safe SGC accent on business reports.
